FOSELEV VFG V3.5.2 — Correctifs ergonomiques

1. Suppression des lignes artificielles « rubrique — contrôle X ».
   Les rubriques affichent désormais uniquement les points de contrôle réellement nommés dans le référentiel courant.
2. Barre fixe en bas : Menu principal / Porteur / Tourelle.
3. Dans une liste de points :
   - appui sur le bouton rond à droite = validation immédiate conforme ;
   - appui sur le texte = ouverture directe du constat.

Attention : les totaux sont recalculés sur les points réellement définis.
