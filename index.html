Première mise en service

Exécute d’abord PHASE_2_MIGRATION.sql, puis IMPORT_REFERENTIEL.sql dans l’éditeur SQL de ton projet Supabase. Ensuite, utilise le même compte sur le PC et l’iPhone pour partager l’historique.

Important : la synchronisation nécessite que l’application soit ouverte depuis une adresse HTTPS, par exemple GitHub Pages. Elle n’est pas prévue pour un fichier index.html ouvert directement depuis le ZIP.
