FOSELEV VFG V3.1.0 — Recherche machine corrigée

LANCEMENT SUR PC
1. Décompresser le ZIP.
2. Ouvrir le dossier FOSELEV-VFG-V3.1.
3. Double-cliquer sur index.html.

La recherche fonctionne désormais même lorsque l'application est ouverte directement depuis le disque (adresse file:///...).
Le fichier parc.js est chargé localement avant l'application.

TEST RAPIDE
- Saisir GM1135 : la machine doit apparaître dans la section Résultats.
- Cliquer sur la machine : le tableau de bord Porteur / Tourelle doit s'ouvrir.
- Revenir : GM1135 doit apparaître dans Machines récentes.
