FOSELEV VFG V3.6.0 — Moteur de rapport

Nouveautés :
- Bouton « Aperçu du rapport » sur le tableau de bord.
- Rapport généré depuis les données sauvegardées de la visite.
- Page de couverture, synthèse des anomalies, chapitres Porteur et Tourelle.
- Charte RAL 7016 / RAL 9010 / RAL 2004.
- Pied de page : Page X / Y uniquement.
- Impression ou enregistrement PDF via le navigateur, sur PC et iPhone.

Tests :
1. Ouvrir une machine et renseigner les relevés.
2. Ajouter éventuellement un ou plusieurs constats.
3. Cliquer sur « Aperçu du rapport ».
4. Vérifier les quatre pages et la pagination.
5. Cliquer sur « Imprimer / Enregistrer en PDF ».
